Numpy

desighned for fast numerical computations, especially with large arrays and matrices. 
It provides a powerful data structure called ndarray, which is a multi-dimensional array that can hold elements of the same type. 
Numpy also offers a wide range of mathematical functions to operate on these arrays efficiently.



python list vs numpy array

1. Numpy arrays are faster than Python lists for numerical operations because they are implemented in C and optimized for performance.

2. Numpy stores data in a contiguous block of memory, which allows for efficient access and manipulation, while Python lists are more flexible but can be slower due to their dynamic nature.

3. uses less memory than Python lists because they are more compact and do not require additional overhead for storing metadata.

4. built in mathematical functions that can operate on entire arrays at once, while Python lists require explicit loops for similar operations.

5. Supports direct vectorized operations, allowing for element-wise computations without the need for explicit loops, while Python lists require manual iteration for such operations.

python me extra meta data store hota hai list ke sath, jaise ki size, type, etc. Numpy arrays me ye metadata nahi hota, isliye wo zyada memory efficient hote hain.
